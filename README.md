# NoA Core - Alpha 0.7

NoA Alpha 0.7 adds first practical tool integrations: live weather, lightweight web lookup, local memory, diagnostics, and OpenAI-backed natural conversation when an API key is saved.

## Install

```bash
npm install
npm run dev
```
